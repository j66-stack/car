# car 车牌识别示例程序
一个基于Python开发、调用百度智能云接口实现车牌识别的简易项目，仅供学习参考。

# 项目简介
本程序通过网络请求调用百度开放平台图像识别API完成车牌解析，本地不内置训练模型。

# 运行说明
地址： https://cloud.baidu.com/
1. 前往百度智能云平台注册账号，申请图像识别API密钥（注册有免费的额度）；
2. 将获取到的 API Key、Secret Key 填入配置；
3. 安装项目所需依赖包后启动 main.py。
